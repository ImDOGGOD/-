# model_warehouse说明（F:\AI\local\model_warehouse）

本目录按"一个模型一个子目录"存放 GGUF 模型源文件与对应 Modelfile，用于随时更换不同强弱、不同特长的模型。

## 与 gguf 目录的分工

- gguf：下载暂存区（robust_download.ps1 等脚本的落点），文件下好后移入本仓库对应子目录；
- model_warehouse：入库存储区，一个模型一个子目录，随用随换。

## 子目录构成

- *.gguf：模型权重源文件
- Modelfile：Ollama 导入配方（FROM ./xxx.gguf）
- download_*.log：下载日志存档

## 更换模型三步

1. 下载：把新模型 GGUF（魔搭 ModelScope 等）放进新子目录；
2. 导入：在项目根目录执行
   `powershell -File model_warehouse\import_model.ps1 -Name "新注册名" -Modelfile "model_warehouse\新模型\Modelfile"`
   或进入该子目录执行 `ollama create 新注册名 -f Modelfile`；
3. 上岗：改 models.yaml 对应角色的 model 字段，保存即生效（界面标题与团队自我介绍会自动更新）。

## 按岗位是否需要"高级"模型？（结论：不必全换）

- 规划/路由：只做分类+计划，4B-7B 足够，上大模型浪费；
- 执行者：答案质量天花板，最值得升级（已于 2026-11-01 升级为 InternLM3-8B-Instruct）；
- 审查员：保持推理型模型（deepseek-r1:8b 已属 8B 级第一梯队）；
- 元问题/编排层：纯代码，零模型。
- 显存约束：8GB 只能"轮流"装一个 7-9B 模型，三岗全上 8B 只会更慢。
